# ИИ-агенты

Агенты — полноценные клиенты движка: видят ту же сессию, что и окно, пользуются теми же
инструментами и спрашивают твоего разрешения на всё, что меняет программу-цель.

## Быстрый способ

1. Открой окно и подключись к игре (или поручи это агенту).
2. Во вкладке **Agent** выбери агента и нажми **Open terminal**.
3. Попроси, например:

   > У меня 37 стрел. Найди их и удвой.

Агент сканирует память, просит изменить значение в игре («выстрели одной стрелой»), сужает
результаты, сохраняет адрес в таблицу и просит разрешения записать 74. Ты нажимаешь **Allow**.

**Open terminal** запускает агента в рабочей папке (по умолчанию
`~/.local/share/engram/workspace`). В ней лежат:

| Файл | Для чего |
|---|---|
| `AGENTS.md` | Инструкция для агента: правила, сценарии, коды ошибок |
| `CLAUDE.md` | Отсылает Claude Code к `AGENTS.md` |
| `opencode.json` | Настройка MCP для OpenCode |
| `.mcp.json` | Настройка MCP для Claude Code и других |

Поддерживаемые терминалы: Konsole, GNOME Terminal, Console (kgx), Ptyxis, kitty, Alacritty,
Ghostty, WezTerm, foot, Xfce Terminal, Tilix и xterm. Можно указать любую команду в настройках.

## Другая папка

```sh
engram agent-init ~/моя-папка
```

Команда дописывает в существующие файлы, не затирая их: другие MCP-серверы и твой текст в
`AGENTS.md` сохраняются.

## Ручная настройка MCP

MCP-сервер — это `engram mcp` (stdio).

**OpenCode** (`opencode.json` в проекте или `~/.config/opencode/opencode.json`):

```json
{ "mcp": { "engram": { "type": "local", "command": ["engram", "mcp"], "enabled": true } } }
```

OpenCode 2.x понимает этот формат и сам переводит его в новый.

**Claude Code:**

```sh
claude mcp add engram -- engram mcp
```

**Codex:**

```sh
codex mcp add engram -- engram mcp
```

Агенты без MCP пользуются CLI: любой инструмент вызывается как `engram <tool> key=value` и
печатает компактный JSON. Оба способа описаны в `AGENTS.md`.

## Подтверждения и политика

| Инструмент | Требует подтверждения, если вызывает агент |
|---|---|
| `write` | всегда |
| `table_set` с `value` или `freeze=true` | всегда |
| `watch` | всегда (ненадолго трассирует потоки игры) |
| `process_control action=pause` | всегда |
| `launch` | всегда (через MCP не предлагается вообще) |

Что происходит дальше, решает политика:

- **ask** (по умолчанию): запрос появляется в окне. Если окно закрыто, запрос отклоняется с
  ошибкой `approval_unavailable`.
- **allow**: агенты действуют без вопросов. Включай только для агентов, которым доверяешь.
- **deny**: все такие запросы отклоняются.

Политику можно сменить во вкладке Agent (действует до перезапуска движка), задать значение при
старте командой `engram config set policy ...` или запустить движок как `engramd --policy ...`.

## Что видно о работе агентов

Лента активности показывает каждый вызов с именем клиента: `claude-code`, `opencode`,
`mcp:<клиент>` и так далее. Сообщения агента (`notify`) выделены жирным и дублируются в
строке состояния.

## Советы

- Назови агенту игру и значение. Значения меняются, только когда играешь *ты*, поэтому агент
  будет просить тебя сделать что-то в игре.
- Чтобы находка пережила перезапуск, попроси цепочку указателей («чтобы работало после перезапуска»).
- С онлайн-играми с античитом агент должен отказаться или предупредить. Engram предназначен
  для одиночных игр и своих программ.
